Rulers and grid

Rulers and the grid are visual aids to help you measure and position things in your image.

Rulers

Menu:
"View >> Show Rulers"

  • Rulers are hidden by default. Select "Show Rulers" to show or hide them.
  • Your choice is remembered, so rulers will be shown or hidden the same way the next time you open an image.
  • A horizontal ruler is shown along the top and a vertical ruler along the left of the image area.
  • The rulers follow the zoom level and scroll position, and a marker shows the current mouse position.
  • Right click on a ruler to change its unit to Pixels, Inches or Centimeters. Both rulers switch together. Pixels is the default.
  • Inches and Centimeters are calculated using the DPI of your display.

Grid

Menu:
"View >> Show Grid..."

Button (main toolbar):
"Grid Settings..."

  • Show Grid - Asks for a cell width (1 to 999 pixels) and draws grey grid lines over the current image at that spacing. Select it again to hide the grid.
  • Grid Settings - Change the cell width. If the grid is hidden it will be shown using the new size.
  • The grid is set per image, so you can have a grid on one image and not another.
  • The grid is redrawn automatically if you change the size of the image.
  • Grid lines stay the same thickness when you zoom in and out.
